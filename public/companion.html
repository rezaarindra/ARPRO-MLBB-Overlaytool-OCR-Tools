STREAM DECK BITFOCUS COMPANION · HTTP

CARA PASANG

  1. Install Bitfocus Companion (gratis) di PC yang tersambung ke Stream Deck.
  2. Di Companion › Connections, tambahkan modul Generic: HTTP Requests. Base URL:
  3. Buat tombol › Press actions › GET › isi URL dari daftar di samping (cukup bagian /api/companion/… bila Base URL sudah diisi).
  4. Tanpa Companion: plugin Stream Deck apa pun yang bisa membuka/mengirim web request juga bisa memakai URL yang sama.
  5. Pakai IP LAN server (bukan localhost) bila Stream Deck tersambung ke PC lain.

PARAMETER

event: ?event=first_blood&side=blue&slot=0. Event: first_blood, turtle_slain, turtle_stolen, lord_slain, lord_stolen. Slot 0–4 = pemain 1–5.

mvp-show: ?side=red&slot=2 (opsional, tanpa parameter = pemain terakhir).
